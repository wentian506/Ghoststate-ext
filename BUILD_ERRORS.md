# Unresolved issues and release blockers — 0.2.2

Current TypeScript builds, 28 unit/security tests, Linux/Windows-target Clippy, 14 Linux and 14 Windows-target-under-Wine Rust tests, Linux and Chromium/Firefox synthetic workflows, local installer checks and npm/OSV advisory scans passed. These results do **not** establish production readiness. Use synthetic credentials only.

1. **No physical Bluetooth:** the development environment had no adapter or usable virtual controller. Windows and Linux receiver/central implementations require real cross-platform hardware testing for discovery, advertising, MTU, reconnects, limits, security and transfers. Eight is a sender software cap, not measured radio capacity. A receiver is reserved for its first peer until stopped, allowing denial of service. Firefox transfer UI used a mock, not radio. See [Bluetooth plan](docs/BLUETOOTH_TEST_PLAN.md).
2. **Windows is not validated:** the x64 EXE was cross-compiled on Linux and smoke-tested under Wine. Installer logic and diagnostics were run in Linux PowerShell against a mocked registry. The new WinRT receiver, real registry and ACLs, OS permissions, actual Chrome/native handshake and Bluetooth have not been tested on Windows. A guarded Windows CI test exists but has not run. Chrome checks the 32-bit registry view before the 64-bit view; conflicting stale registrations need careful inspection.
3. **Missing platforms:** macOS has sender source but no supplied binary or receiver; neither build nor hardware is validated. No Android/iPhone companion exists, and normal Chrome on phones cannot install this desktop extension. Safari's native Swift/XPC bridge is not implemented. Desktop-engine responsive emulation is not a real-device test.
4. **Store submission incomplete:** no Store upload, review or approval has occurred. Publisher account verification, public HTTPS privacy policy and Limited Use disclosure, real support/security contact, accurate listing/certifications, a trusted public companion download and any required reviewer instructions remain the publisher's responsibility. This package can be uploaded as a draft; it is not certified for publication. Resolve security and hardware gates before submitting.
5. **No independent security assurance:** no security audit, protocol review, formal verification, fuzzing or penetration test. Site and challenge detection are heuristic; a selected site can read or submit filled data. Local browser/native messages contain a selected credential in plaintext, and a compromised endpoint can expose secrets. Use synthetic accounts only.
6. **Unsigned artifacts:** browser ZIPs, both native binaries and companion packages are unsigned developer artifacts. The Windows host may trigger security warnings. SHA-256 checksums provide corruption detection, not publisher authentication. Production platform signing/packaging and installer hardening remain outstanding.
7. **UI static warnings:** Firefox `web-ext lint` reported zero errors and three `UNSAFE_VAR_ASSIGNMENT` warnings for dynamic `innerHTML`. Values are escaped, CSP forbids inline script, and an XSS regression passes, but these are not a substitute for independent review or a possible DOM-only rendering refactor.
8. **Accessibility:** 103 automated axe-core checks passed, but actual screen-reader, cognitive-accessibility, assistive-technology and broader device reviews remain outstanding.
9. **Dependencies:** npm audit and OSV matched zero advisories in the current scan (194 exact Cargo.lock crates); a prior local `cargo-audit` installation timed out and was replaced by OSV querying. A clean npm install may emit a test-only `whatwg-encoding@3.1.1` deprecation warning. Continue scanning; old results are not guarantees.
10. **Protocol and feature boundaries:** both peers must use BLE v2/eight-digit comparison; v1 is rejected. A 120-second transfer expiry limits delivery but does not revoke an imported password. No automatic cloud sync, cross-origin SSO following, iframe/shadow-DOM mapping, persistent device roster, cookie/session transfer, OTP/CAPTCHA solving, passkeys, breach lookup, shared vault or lost-passphrase recovery.
11. **Hosted CI unrun:** the included Linux and disposable Windows GitHub Actions jobs have not been executed on the hosting service. Wine's XDG-runtime warning did not prevent its smoke tests; Wine is not a Windows OS or Bluetooth test. Browser integration suites ran sequentially to avoid resource contention.

## Prior security-relevant defect

Version 0.2.0 used deferred dialog focus that could redirect quickly typed text into the profile-name field, potentially displaying a secret. Version 0.2.1 and later set initial focus synchronously and include a deterministic regression. If an older build was used, inspect profile names and treat any affected secret as exposed. Change any affected website password; if the master passphrase appeared there, migrate to a new vault and passphrase and treat prior backups as compromised. This correction is not a security audit.
