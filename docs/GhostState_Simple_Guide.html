A plain-English guide

GhostState,
in simple words.

What it is, why someone might use it, and the problems to know about.

Important: this is still a prototype.

It has not had an independent security review. For now, use only made-up test accounts and passwords—not real or important ones. If you tried version 0.2.0, check profile names for accidentally typed passwords and change any affected password on its website.

What is it?

GhostState is a website sign-in helper. It can keep a username and password in a locked digital box on your computer. After you teach it a website’s sign-in screens, it can fill matching fields with your approval or a temporary automatic setting.

Why might someone want it?
01Less repeated typing

It may help when the same website asks for a username and password on separate screens.

02Stored on your device

The saved vault stays on your device by default, rather than in a GhostState cloud account.

03You stay involved

You choose the site and fill mode, and complete security checks yourself.

The short version
1. Choose a site2. Teach its screens3. Choose fill mode4. Finish yourself

Do people have to use it? No. Established password managers already offer similar help and are a better choice for important accounts while GhostState is still being tested.

A simple example

How would someone use it?

Imagine Riya has a pretend school website and a fake test login. Here is what she would do.

1
Install the browser add-on.

It adds GhostState to a supported desktop browser. The upgraded dashboard runs inside the extension; no separate web server is needed.

2
Create a vault and add a practice login.

Riya chooses a master passphrase for the vault, then adds the practice website address and fake username and password.

3
Choose the site and allow access.

She selects the site in GhostState and accepts the browser’s permission request only if she trusts that website.

4
Teach each sign-in screen.

Under Workflows (called Flows in the narrow-screen navigation), she shows which field is the username. If the password is on a second screen, she moves there herself and teaches that screen too.

5
Choose how to fill.

She can use Review & fill, or turn on automatic fill for the chosen tab for up to 10 minutes. GhostState does not press Sign in; some sites may react automatically to filled fields.

6
Complete extra checks herself.

If the website asks for a one-time code, a picture test, a passkey or a security question, Riya completes it herself.

What about another nearby device?

A sender can pair up to eight devices in software, compare a code with each and approve each transfer. Experimental Linux and Windows receivers handle one sender at a time. This needs a separate helper program and has not been tested with real Bluetooth devices yet. Android and iPhone apps are not included.

It does not move an already signed-in session. Once another device receives a password, that password can remain usable until you change it with the website.

Possible problems

What could go wrong?

These are practical limits—not things GhostState can magically fix.

The website changes its sign-in page.

GhostState may no longer recognize it. What to do: sign in yourself and, if appropriate, teach the changed screen again.

The login opens at a different address or in an unusual box.

Some sign-in layouts and address changes are not supported automatically. What to do: use a separately approved profile where supported, or sign in manually.

A code or security check appears.

Enter one-time codes and complete picture tests, passkeys and security questions yourself. GhostState may not recognize every kind of challenge.

You forget the master passphrase.

There is no recovery service. Even a saved backup needs its original passphrase. Resetting the vault removes its saved data; your website accounts still exist.

Your computer is lost or breaks.

There is no automatic GhostState cloud sync. You can upload an encrypted backup yourself; restoring it needs its original passphrase.

Nearby sharing does not work.

It needs compatible devices and a separate helper program. Real Bluetooth transfer has not yet been tested, so do not rely on it; sign in manually instead.

Remember: GhostState is designed to help with a sign-in, not to defeat a website’s rules or security checks. It will not work with every website.

Privacy, safety and next steps

The honest answers

Where do my login details go?

The vault is encrypted and stored locally; there is no GhostState cloud service. You may upload an encrypted backup yourself. A website receives what is filled; a compromised site could steal it, especially with automatic fill. Nearby transfers require your approval.

What does it learn about a website?

It is designed to remember the arrangement of sign-in fields, not the whole page or screenshots. It does not save the one-time codes you enter.

Does “encrypted” mean nothing can go wrong?

No. It means the saved data is locked with your passphrase, but a weak passphrase or a compromised computer can still put it at risk. The software has not been independently security-reviewed.

Will it work on my computer or phone?

Chrome-family and Firefox workflows were tested with fake accounts on Linux. The dashboard adjusts to phone-sized screens, but this is not a phone app. Android and iPhone companions are not included. Windows and macOS and physical Bluetooth remain unverified; Safari is incomplete.

Does the extension need a server?

No. The upgraded dashboard runs inside the installed extension. Nearby sharing additionally requires a separate local companion and remains experimental.

A few words you will see

Vault · the locked box for saved details.
Portal · the website you want to sign in to.
Workflow · the sign-in screens you teach it.
Companion · an extra program for nearby sharing.
Bottom line

GhostState aims to make repeated sign-ins easier while giving you control. It is still experimental. For real accounts today, use a well-established password manager instead.

Based on GhostState 0.2.2 documentation and test status, 19 November 2026. Capabilities may change as development continues.
